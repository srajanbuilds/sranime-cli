# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| < 5.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or exploit within `sranime-cli`, please do **not** open a public issue.

Instead, please report security vulnerabilities via GitHub Private Security Advisories on the repository:
https://github.com/srajanbuilds/sranime-cli/security/advisories/new

We will review reports within 48 hours and work with you to coordinate a responsible disclosure and patch release.

## Third-Party Media Disclaimer

`sranime-cli` does not host, upload, or store any media. It operates as a web scraper that streams public links directly into local media players (such as `mpv` or `vlc`). Users are responsible for ensuring compliance with applicable local laws and regulations.
